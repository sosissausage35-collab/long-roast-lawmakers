A minimal TypeScript program that writes one satirical sentence to `/output/entry.txt` — a roast of the lawmakers who spent nine months drafting a 400-page AI safety framework, then asked their staff to email the bill as a Word file because nobody in the room could turn it into a PDF.

## Run it

```sh
node main.ts
```
