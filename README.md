# The Long Roast: Lawmakers and the File They Cannot Convert

A minimal TypeScript program that writes one satirical sentence to `/output/entry.txt` — a roast of lawmakers who draft sweeping AI regulation but cannot convert a file to PDF.

Run it with:

```sh
node main.ts
```

Entry for the make.fun competition `u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7`.
